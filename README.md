Dashboard de Gestão de Frota — Power BI

Dashboard desenvolvido para uso corporativo, com foco no controle e análise 
da frota de veículos. Os dados neste repositório são fictícios e gerados 
para fins de demonstração.

Sobre o Projeto

Painel criado para centralizar o monitoramento da frota corporativa, 
permitindo análise de custos de abastecimento, consumo por veículo 
e desempenho por motorista.

Indicadores Analisados

- Total gasto em combustível por período
- Custo médio por litro (Gasolina, Etanol, Diesel)
- Km rodados por motorista e por veículo
- Gasto por centro de custo
- Perfil da frota: Próprio, Locado e Agregado
- Ranking de motoristas por consumo e custo

Ferramentas

- Power BI Desktop
- Power Query (ETL e tratamento dos dados)
- DAX (métricas e KPIs)
- Excel (fonte de dados)

Como Usar

1. Clone ou baixe este repositório
2. Abra o arquivo `BI_FROTA.pbix` no Power BI Desktop
3. Atualize o caminho da fonte de dados para o `DADOS_FROTA.xlsx` na sua máquina
4. Atualize os dados e explore o dashboard

[!] Observação

Os dados utilizados neste repositório são **fictícios**, gerados exclusivamente 
para fins de portfólio. O projeto original foi desenvolvido para ambiente 
corporativo com dados reais da empresa.
